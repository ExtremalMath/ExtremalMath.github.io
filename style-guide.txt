STYLE GUIDE
站点样式与设计规范（合并版）
============================================================

来源：由原 style-guide.txt（格式规范）与 design-review.txt（设计审查与
      逐页优化建议，2026-10-17）合并而成。审查结论（G1–G4、N1、C1、Y1、
      P2、A1–A5、M1–M3、S1、T2、L4 及首页 hero 专章）已吸收为本规范的
      正式规则或「已决议事项」（见第十四节）。
状态：仅本地维护文档，不推送（推送政策见 push-rules.txt）；网站已不链接
      本文件。原文中的重复表述已合并，规则一律给出可直接执行的值。
用途：extremalmath.github.io 全站唯一样式规范。新页面发布前必须逐条过检；
      旧页面在「被碰到」时顺手对齐。规范刻意精简——记不住的规则等于没有。

============================================================
一、设计总则
============================================================

- 基调：干净、安静、易读。空间与细线完成排版，不用装饰。
- 每个页面四段式（见第五节），全站统一。
- 动效约束：无声音、无动效、无弹窗；唯一允许的动效是悬停颜色过渡，
  时长统一 0.15s。
- 所有规则值（颜色、字号、间距）来自本规范，页面内不另造值。

============================================================
二、配色（8 色，禁止新增）
============================================================

全站颜色收敛为 8 个 CSS 变量（定义于各页 :root），禁止任何游离色值：

  --bg           #fff      页面背景
  --cream        #fbfaf7   侧栏、安静区
  --ink          #1b1b1b   正文
  --muted        #6d6a63   注释、日期、细字（绝不用于正文）
  --line         #e3ded4   浅分隔线（行下、h2 下、页脚上）
  --accent       #8c2f39   链接、标题线、关键标记
  --accent-dark  #6b2229   链接悬停
  --green        #3a5a40   仅 About 头像 ℵ 一处

落实：
  body { color: var(--ink); background: var(--bg); }
  a    { color: var(--accent); transition: color .15s; }
  a:hover { color: var(--accent-dark); }
  .muted / footer / 日期 { color: var(--muted); }
  分隔线用 border-bottom: 1px solid var(--line)（h1 收尾线除外，见第三节）。
教训：cv.html 曾硬编码 #f4f4f4，已改回变量。新增页面先写变量引用，
      杜绝出现第二个游离色值。

============================================================
三、字体与排版
============================================================

- 系统字体栈，禁止 Web 字体：
  -apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif
- 正文字号不写死，继承浏览器默认 16px（N1 已决策：now.html 的 17px 已去除，
  全站不再出现显式 body font-size）。
- 行高 1.7。
- h1 = 1.8em + 下方 2px 绛红收尾线（border-bottom: 2px solid var(--accent)）。
- h2 = 1.2em + 下方 1px 浅线（border-bottom: 1px solid var(--line)）。
- 安静文字（页脚、日期、注释）= 0.85–0.92em 灰色；页脚下限 0.85em
  （M3：materials.html 曾 0.82em，已列入对齐项）。
- 加粗仅标记关键词，每页 ≤2 处；斜体仅书名与数学符号（H、n、t）。
- 首页 h1 例外见第十一节（仅 index.html 允许放大居中）。

============================================================
四、间距刻度（G1 落地）
============================================================

- 唯一合法取值：4 / 8 / 12 / 16 / 24 / 32 / 48（px）。
  所有 padding、margin、gap 只取刻度值；旧页被碰到时对齐到最近刻度。
- 统一锚点（取代此前各页漂移值 30–36px / 40–72px / 0.15s–0.2s 混用）：
  · 区块上距：h2 前 32px；块与块之间 24px。
  · 页脚上距：48px。
  · 列表行内 padding：16px（res-row、talk 行统一；books 紧凑行允许 12px）。
  · 侧栏：段与段间距 20px；技能网格 gap 12px（about 现状，保留）。
  · 悬停过渡时长：统一 0.15s（transition: color .15s）。
- 落实示例：
  .block { margin-top: 32px; }
  .res-row { padding: 16px; }
  footer { margin-top: 48px; font-size: .85em; color: var(--muted); }
  注：research-directions 的 .direction h2 自定义类同理取刻度值（R1）。

============================================================
五、页面结构（四段式）
============================================================

1. back link：置顶（高于一切）、绛红加粗、无下划线（悬停才显）、
   命名父页——"← Back to Materials"，不用裸 "Home"（父页即 Home 除外）。
2. page head：h1 + 一句安静副题 + 2px 绛红收尾线。
3. 主内容：720px 单列居中，上 40px、下 60px。
4. 页脚：1px 浅线 + 两行安静小字居中——
   "© 2026 ExtremalMath" / "Last updated <Month Day, Year>"，
   0.85em 灰色，除此之外页脚不放任何内容。

已批准例外（登记后方可保留，新页面不得仿效）：
- about.html：右侧 232px 侧栏（Now / Explore / 更新日期），允许小节图标
  与绿色头像。
- now.html：topbar（back-link + 右侧 "Current Work"）+ 双栏，系 JS 动态
  渲染所致（N3 合理偏离）；其 aria-live / aria-current / :focus-visible /
  hash 路由 / 加载竞态防护是全站可访问性标杆，新页面参考它实现（N2）。
- books.html：顶部 sticky "For study use only" 声明条（常驻需求，B1）。
- cv.html / cv-zh.html / cv-en.html：15px / 13.4px 小字号体系系 PDF 打印
  优化（C2），屏幕媒体查询下可适当放大（可选）。
- competition.html：页脚日期用「年+月」制（"Last updated Oct 2026"，
  2026-10-18 用户指示）；与 cv 年月制并为例外，不上升全站规范。

============================================================
六、组件规范
============================================================

- 文件列表（books / notes / code / talks 等）：每行一个整行链接 +
  右侧小标签（PDF / CPP）+ 行下 1px 浅线 + 悬停文字转绛红；
  无卡片、无阴影、无箭头（C1：cv.html 语言选择卡片已扁平化为
  res-row 整行链接，为全站唯一曾违规处，教训入册）。
- 动效：仅悬停颜色过渡 0.15s；禁止入场动画、视差、打字机等一切动效。
- aleph 占位机制见第九节。
- 占位文案统一带句号："Coming soon."（P2：teaching.html 曾缺句号）。

============================================================
七、链接规范
============================================================

- 页间链接同标签打开；文件链接（PDF、代码）新标签 target="_blank" +
  rel="noopener"；外部站点链接同样补 rel="noopener"（S1）。
- back link 命名父页（见第五节 1）。
- 已上线文件改名须经用户明确批准，并满足两条件：全站引用同步更新、
  迁移全程留档（.workbuddy/pdf-rename-migration/）。2026-10-18 用户末次裁决放弃
  托管层 301 要求，旧 URL 允许直接 404；改名即可上线，不再强制 301（trouble.txt 更新记录末条）。
- 新文件命名即按第十三条执行，不留到推送前才改名。

============================================================
八、可访问性
============================================================

- 每页 :root 区必须包含全局焦点样式（G2，一行规则 × 全站）：
  :focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }
- 媒体查询中给过渡一个降级出口（G3）：
  @media (prefers-reduced-motion: reduce) { * { transition: none; } }
- 图片必须有 alt；aleph 占位时 aria-label 即最终 alt。
- 文件行建议加 aria-label="文件名 · 大小"（H2，可选）。
- 移动端：about 侧栏转横滑胶囊（保留）；极小屏（<360px）双按钮
  flex-wrap 已验证无溢出（E2）。

============================================================
九、图片（PICTURES）
============================================================

- 全部图片放 picture/；个人图片（头像、本人照片）放 picture/private/。
- 命名：英文小写、下划线分词（profile.png、tour_map.png）；
  扩展名 .png / .jpg 优先，.jpeg / .webp 亦可。
- 未放图时用 aleph 占位：
  <div class="aleph" data-pic="private/profile" role="img" aria-label="Profile picture">ℵ</div>
  data-pic 为 picture/ 下的路径（不含扩展名），aria-label 即最终 alt。
- 自动替换：页面加载 picture.js，按 .png → .jpg → .jpeg → .webp 顺序探测
  picture/<data-pic>.<ext>，命中即把 ℵ 换成 <img>，无需改页面；
  data-pic 带扩展名时只试该扩展名。探测不到时保持 ℵ，读者看不到报错。
- 手动替换：直接写 <img src="picture/private/profile.png" alt="...">
  并删除占位，保留原有边框样式。
- 有图片槽的页面在 </body> 前加载 <script src="picture.js"></script>，
  无槽页面不加载。
- 图片保持小体积；picture/private/ 推送后即公开，只放愿意公开的内容
  （A5：profile.png 暂不添加，任何智能体不得主动放入）。

============================================================
十、写作与文案（可读性）
============================================================

- 全站英文；短句、常用词（CET4 为基）：use 不写 utilize，start 不写
  commence，help 不写 facilitate。
- 一页一事；一页几分钟读完；长内容拆子页。
- 日期格式："Last updated Oct 17, 2026"（短月份）；改动当日更新，
  同日改动日期不变。
- 标点口径：破折号用 em dash（—），不用连字符 "-"（Y1）；
  站内路径引导写 "See the Materials → Course Essays page." 这种完整句
  （A2：曾写 "Materials->Course essays" 且缺句号，已修正）。
- 页面骨架纯英文；中文专名（教师姓名、志愿者机构名）允许中英并存，
  不扩散进正文句子（G4）。
- 新页面不加图标（About 小节图标是唯一例外）。
- 无声音、无弹窗、无动效——文案与交互共同保持安静。

============================================================
十一、首页 hero 专章（仅限 index.html）
============================================================

目标：首屏"更有生气"，但只能靠排版层级与留白节奏，不能靠动画。

- h1 仅首页可放大：2.4–2.8em、字重 600–700、居中独占一行；
  内页 h1 一律 1.8em，此放大不写入全站规范。
- 标题下放 64–96px 宽、2px 绛红短线居中作锚点（替代通栏长线；
  长线留给内页 page-head）。
- 居中只用于 hero 区（标题+副题）；正文与列表立即恢复左对齐。
- 三层视觉层级：
  第 1 层 大标题（读者第一眼，唯一定焦元素）；
  第 2 层 副题（0.95–1.05em 灰色，紧接标题下，间距 8–12px）；
  第 3 层 引言与入口（正文级，左对齐，与副题间距 24–32px）。
- 引言 ≤40 词、加粗 ≤2 处（保留 "Extremal Graph Theory"）。
- CTA 只保留 2 个整行链接（padding 12px），置于引言之后、Recent Updates
  之前；声明 / Style guide 属 meta 链接，留在日志之后，不参与首屏竞争。
- 首屏信息带（标题组/引言/入口/日志）≤4 个。
- 不喧哗红线：不引入 Web 字体、不引入新颜色、不加背景图/纹理；
  不加任何动画；悬停仅颜色过渡 0.15s。
- 实施顺序：先引言瘦身+入口排布（收益最大），再标题居中+display 字号+
  短线锚点，最后可选做访客计数加载失败静默隐藏（L4）。

十二、上线前五检（每个页面逐条通过）
============================================================

1. back link 置顶、命名父页。
2. page head 恰一个 h1 + 一句副题 + 2px 绛红线。
3. 页脚恰两行安静小字，无其他内容（about 日期在侧栏）。
4. 日期短月格式，改动当日更新。
5. 链接检查：.workbuddy/check_links.py 全站 0 失效；文件与引用同批上线；
   页链接同标签、文件链接新标签 noopener。

============================================================
十三、文件与命名
============================================================

- 发布资源命名：英文、小写、单词间下划线（twenty_four_game.cpp、
  gtm_244_bondy_murty_graph_theory.pdf）；已上线文件改名条件见第七节。
  改名与命名的**操作级细则、匹配模式、标准流程**见 `.workbuddy/rename-rules.md`
  （含 `validate_filenames.py` 一键校验），新增/改名文件先依其定名。
- 维护文档（*.txt 规范类）命名：英文小写、连字符（style-guide.txt、
  push-rules.txt、trouble.txt）；除 README 外仅本地保留、不推送。
- 编码与格式：UTF-8 无 BOM；行结束符 LF；文件尾留一个换行；不用 tab
  （缩进用空格）；无尾随空格。
- 分隔符约定（各维护 txt 通用）：一级节 ======（60 个等号）；
  二级节 ------；列表用 "- "（减号+空格）；步骤序列 ①②③；检查清单 "□ "。

============================================================
十四、维护规则与已决议事项
============================================================

维护规则：
- 规范变更流程：先改本文件 → 同轮同步 updates.js 顶部当日条目
  （≤100 英文单词，同日合并）+ about.html + index.html → 被改页面
  页脚日期改为当天。
- 悬停样式统一例外（2026-10-22 用户指示）：全站所有 <code>a</code> 链接悬停时，文字变深酒红 #8B0000 并左倾 <code>skewX(-10deg)</code>（<code>transform-origin: left center</code>，过渡 0.2s ease）；但标记为 "Back to …" 的页面导航链例外——它们用 <code>.back-link</code> 或 <code>.btn</code> 类，保持原样式（绛红 + 下划线）。规则代码：
  <code>a:not(.back-link):not(.btn):hover { color: #8B0000; transform: skewX(-10deg); transform-origin: left center; transition: color 0.2s ease, transform 0.2s ease; }</code>
- 任何对规范的偏离必须在本规范第五节登记，否则视为违规。
- 本地与远端保持一致；只推差异文件（详见 push-rules.txt）。
